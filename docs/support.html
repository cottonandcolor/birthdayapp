Help & feedback

For bug reports or feature requests, open an issue on the project repository (GitHub account required):

github.com/cottonandcolor/birthdayapp/issues

Common questions

Notifications
Enable notifications in iOS Settings → Birthday → Notifications so reminders can fire.

iCloud
Sign in to iCloud on your devices and allow the app to use iCloud if you want data to sync.

Microphone / voice
Voice add uses the microphone only when you start voice entry; you can allow or deny in the system prompt.

Calendar
Calendar access is optional and only used if you export or add events from the app.
